# SQL Server DBA Lab 🚀

Repositorio personal de aprendizaje de **SQL Server y administración de bases de datos**, basado en el curso de Udemy que estoy estudiando y reforzado con retos propios orientados a un puesto de DBA Junior.

> Nota: este es material original de práctica, no una copia del contenido de pago de Udemy.

## Herramientas
- SQL Server (instancia local de desarrollo)
- SQL Server Management Studio (SSMS)
- Git y GitHub

## Estructura
```text
sql-server-dba-lab/
├── apuntes/         # 10 módulos con plantillas
├── laboratorios/    # Scripts T-SQL ejecutables
├── retos/           # Ejercicios de cada semana
├── soluciones/      # Mis respuestas
├── evidencias/      # Capturas sin datos sensibles
├── proyectos/       # BancoLab y proyectos futuros
├── recursos/        # Enlaces de estudio
└── PROGRESO.md      # Seguimiento
```

## Inicio rápido
1. Conectarme desde SSMS a mi instancia **local** de SQL Server.
2. Abrir `laboratorios/01_crear_bancolab.sql` y ejecutarlo en la instancia de prácticas.
3. Verificar las tablas y los datos de ejemplo.
4. Ejecutar `laboratorios/02_consultas_de_ejemplo.sql`.
5. Resolver `retos/semana_01.md` y guardar respuestas en `soluciones/`.
6. Actualizar `PROGRESO.md` después de cada sesión.

**Seguridad:** usar solamente datos ficticios. Nunca publicar contraseñas, cadenas de conexión, respaldos reales, datos de clientes ni capturas que los expongan. No ejecutar estos scripts en producción.

## Meta
Dominar consultas, diseño, seguridad, respaldos, restauración, monitoreo y resolución de incidentes básicos de SQL Server.
