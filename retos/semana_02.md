# Semana 2: Diseño de datos

1. Dibuja relaciones Clientes -> Cuentas -> Movimientos.
2. Identifica PK, FK, tipos de datos y restricciones en cada tabla.
3. Crea una tabla nueva dbo.Sucursales con SucursalID INT IDENTITY PK, Nombre NVARCHAR(80) NOT NULL y Ciudad NVARCHAR(60) NOT NULL.
4. Inserta tres sucursales ficticias.
5. Explica por qué DECIMAL(12,2) es más apropiado que FLOAT para un saldo monetario.
6. Prueba en la base de laboratorio qué ocurre al insertar una cuenta con ClienteID inexistente; anota el error sin deshabilitar la FK.
